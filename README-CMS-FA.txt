ابتدا از پروژه بکاپ بگیرید. محتویات ZIP را در ریشه پروژه جایگزین کنید. هیچ فایل env یا schema تغییر نمی‌کند.
سرور را متوقف کنید و اجرا کنید:
npx tsx scripts/install-cms-settings.ts
npx tsc --noEmit
npm run dev

آپلود لوکال در .cms-media انجام می‌شود. این پوشه را به Git اضافه نکنید و از آن بکاپ بگیرید. برای VPS متغیر CMS_MEDIA_DIR را به مسیر دائمی قابل نوشتن خارج از پوشه انتشار تنظیم کنید و فایل‌های .cms-media را به آن منتقل کنید. در Netlify بدون فضای دائمی، مسیر قدیمی دیتابیس باقی می‌ماند و مشکل اتصال ممکن است تکرار شود.
تست: ویرایش مقاله پیش‌نویس، محصول و خدمات و پروژه موجود، ذخیره تنظیمات و مشاهده صفحه عمومی، آپلود تصویر و باز کردن URL آن. روی داده واقعی تغییر آزمایشی غیرضروری ندهید.
این نسخه تنظیمات تماس و متن اصلی و SEO صفحه اصلی را اضافه می‌کند. طراحی، JSON تخصصی، حذف دائمی و SEO اختصاصی محصولات در اختیار توسعه‌دهنده باقی مانده است.

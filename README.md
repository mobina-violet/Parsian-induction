### درباره پروژه
یک وب‌سایت شرکتی مدرن برای معرفی محصولات، پروژه‌ها و دریافت درخواست مشاوره شرکت پارسیان.  
پروژه با تمرکز روی تجربه کاربری خوب، سرعت و ساختار تمیز توسعه داده شده است.

### ویژگی‌های اصلی
- معرفی محصولات (کوره‌های ذوب و فورج)
- نمایش پروژه‌های انجام‌شده با فیلتر بر اساس صنعت
- فرم درخواست مشاوره
- طراحی ریسپانسیو و مدرن
- اتصال به دیتابیس با Prisma

### تکنولوژی‌ها
- **Frontend:** Next.js (App Router) + TypeScript + Tailwind CSS + shadcn/ui
- **Backend:** Prisma ORM + PostgreSQL
- **UI/UX:** فونت ایرانی‌سنس + کامپوننت‌های سفارشی

### وضعیت فعلی
در حال توسعه  
- ساختار اصلی و کامپوننت‌ها آماده است  
- دیتای متنی و تصاویر در حال تکمیل می‌باشد  
- هنوز روی دامنه واقعی دیپلوی نشده
